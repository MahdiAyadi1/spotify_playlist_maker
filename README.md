# Spotify Playlist Maker

A simple tool to create and populate Spotify playlists using the Spotify Developer APIs.

## Setup

1. Install Python 3.8 or newer.
2. Clone the repository or place the project files in a folder.
3. Install dependencies (preferrably in a virtual environment):

```bash
pip install -r requirements.txt
```

4. Create a Spotify Developer application at https://developer.spotify.com/dashboard/applications.
5. Note the Client ID and Client Secret.
6. Create .env file and Set environment variables for Spotify credentials (follow .env.example).

## Running the project

Run the main script from the project folder:

```bash
python src/main.py
```
